# LP Assets Organize

入稿素材（写真 / .ai / .psd / カンプPDF）を、これから作るLPのセクション構成に合わせて再配置・リネームする。
ゴールは「`img src` にそのまま使えるファイル名」と「元ファイル名に戻れる対応表」の両立。

## プロセス

### 1. 棚卸し
まず全ファイルを把握する。Bash でまとめて取る:
```bash
find . -type f -not -path '*/node_modules/*' -not -path '*/.git/*' | sort
for f in <対象フォルダ>/*; do du -h "$f" | cut -f1; sips -g pixelWidth -g pixelHeight "$f" 2>/dev/null; done
```
- サイズ・ピクセル寸法を全件記録する（縦横判定、重複判定、重いファイルの検出に使う）。
- 文字化けフォルダ名（例: `“ü¨e` は「入稿」の化け）はここで気づいて後で解消する。

### 2. LP構成の把握
グループ分けは**LPのセクション順**を軸にする。必ず以下を見る:
- カンプPDF（PC確認用など）の1ページ目を Read してセクション構成を書き出す。
- ファイル名だけで判断できない画像（スクショ、`01_img1` のような連番、人名.jpg）は Read で中身を確認する。

### 3. グループ定義
基本形。案件に合わせて増減し、フォルダ名はセクション順に2桁連番を振る:

```
<project>/
├── design/             カンプPDF・.ai・.psd（Webに直接載せない原稿）
├── assets/
│   ├── 01_fv/          FV・キービジュアル
│   ├── 02_facility/    店舗・施設・外観
│   ├── 03_session/     レッスン・サービス提供シーン
│   ├── 04_program/     メニュー・プログラム種別
│   ├── 05_target/      ターゲット・利用シーン・背景素材
│   ├── 06_app/         アプリ・UIモック
│   ├── 07_staff/       スタッフ・プロフィール
│   └── 08_access/      地図・アクセス
└── ASSETS.md
```

### 4. リネーム規則
- 半角英数字・ハイフン・アンダースコアのみ。スペース・日本語・全角記号・二重ドット（`02..jpg`）は排除。
- `<被写体>_<補足>_<撮影番号>.ext` の形。撮影番号（`36-3`, `494A5020`, `iStock-2192745798` 等）は**必ず残す**。元写真との照合に使うため。
- 縦位置は `_vertical`、原寸は `_original`、切り抜きパス付きは `_clipped` を付ける。
- 連番モックは `app_screen_1.png` のように意味＋連番に統一する。
- 日本語名は英語に置き換える（外観→exterior、フロント→front、ロッカールーム→lockerroom、緑ぼかし→bg_green_blur など）。

### 5. 移動の実行
- **`mv` で移動する。コピーはしない**（重複と容量増を避ける）。削除は一切しない。
- 1本のスクリプトに `mv` を全件並べて実行し、最後に旧フォルダの `ls -A` で残りが空であることを確認してから `rmdir` する。
- 実行後 `find . -type f | wc -l` で移動前後のファイル数が一致することを確認する。

### 6. ASSETS.md の生成
プロジェクト直下に書く。含めるもの:
- ディレクトリツリーと各フォルダの用途
- フォルダごとの表: `新ファイル名 | 元ファイル名 | サイズ（WxH）| 備考`
- 備考セクション: 同一素材の解像度違い、重い原稿（.ai/.psd）の書き出し要否、解像度不足（Retina非対応）の画像

### 7. 報告
ユーザーには以下を簡潔に伝える:
- 新しいツリー（フォルダ名＋ファイル数）
- リネーム方針（撮影番号を残した、対応表は ASSETS.md にある）
- LP制作時の注意点（重複、重いファイル、解像度不足）

## 判断ルール
- ユーザーが「フォルダ数やリネームは任せる」と言った場合のみ物理移動まで行う。指示がグループ分けだけなら、まず分類案と ASSETS.md を提示し、移動は次のステップとして提案する。
- 中身が判別できない画像は推測せず Read して確認する。
- .ai / .psd は design/ に隔離し、assets/ には書き出し済みの Web 用画像だけを置く。
