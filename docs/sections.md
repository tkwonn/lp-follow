## 動的セクションの実装メモ

- **FAQ**: 見出し帯は画像。Q/A は実テキスト（`details/summary`）。Q 帯背景色・シェブロン・A 部の罫線は CSS で再現し、PDF 画像と重ね合わせで検証する。FAQ 以降（Access、フッター CTA）は固定 Y にせず自然に押し下げる。
- **Instructor**: 見出し帯は画像。カードは HTML（写真・名前・紹介文）。3 名中 2 名は写真・紹介文が未入稿（ベージュのプレースホルダー）。PC は 3 枚横並び＋矢印、SP は 2 枚＋矢印。WordPress 連携方法は要入力。
- **ハンバーガー**: PC-Menu / SP-Menu の展開図を元に HTML で実装（button、Escape で閉じる、フォーカス復帰）。
- **CTA**: 当たり判定の座標のみ保持し「リンク未設定」を表示。`href="#"` は使わない。
- **フッター黒帯 CTA**: デザイン最下部にあるが固定バーの可能性あり。確認まではページ末尾に静的配置。
