## 検証（Figma フレーム vs PDF 画像化）

- 方法: `get_screenshot` で各フレームを PDF と同じ倍率で取得（PC 本体・SP 本体は 1/2 倍、メニューは等倍）。
  PDF は `pdftoppm -r 36`（1/2 倍）/ `-r 72`（等倍）で画像化。`tools/pngdiff.py` でグレースケール化し、
  差 >48/255 の画素の割合と、100px 帯ごとの不一致率を算出。結果は `docs/compare/pngdiff-2026-09-07.jsonl`。
- 画像は `docs/figma-frames/`（Figma）、`docs/pdf-pages/`（PDF）、切り出し比較は `docs/compare/`。

- 差分が 1% を超える面は、目視で上端・下端・不一致率の高い帯を切り出して比較した結果、
  レンダラ差（アンチエイリアス、文字の太り、写真の再サンプリング）と 1px 程度の縦ずれによるもので、
  要素の欠落・位置ずれは確認できなかった。Figma 側スクリーンショットが 376px 幅（PDF は 375px）で
  端 1 列が半端画素になることも差分に含まれる。
- **SP-2 / SP-3 の「PDF より 88px / 77px 短い」問題は解消。** PDF 側も下端に 92px / 80px の余白があり、
  Figma の描画下端との差は 4px / 3px。末尾要素の欠落ではなく、ページ余白を見ていたものだった。
